# TimeTree 公開予定表スターター

このファイル一式は、GitHub Pagesで公開する予定表の「表示部分」のたたき台です。
TimeTreeから予定を取得する連携は含まれていません。events.json は表示確認用のサンプルで、実際の稽古予定ではありません。

## ファイル
- index.html: 月間カレンダー／日付順リストの表示、予定種別フィルター
- events.json: 公開してよい予定だけを入れるデータファイル

## events.json の形式
各予定は次の形で追加します。
{
  "date": "2026-11-01",
  "title": "稽古（工学部）",
  "startTime": "18:00",
  "endTime": "19:30",
  "location": "工学部道場",
  "note": ""
}

title は次の4種類のいずれかと完全一致した予定だけ表示されます。
- 稽古（工学部）
- 稽古（農学部）
- OB稽古会（工学部）
- OB稽古会（農学部）

公開前に、サンプル日程を削除し、demo を false に変更してください。
公開用ページに入れるのは公開してよい情報だけにしてください。

## GitHub Pages で公開する大まかな手順
1. GitHubで新しいリポジトリを作成する（公開リポジトリ）。
2. index.html と events.json をリポジトリのルートへアップロードする。
3. Settings → Pages で公開方法を設定する。
4. 表示されたURLを開いて、スマートフォンでも確認する。

## 注意
TimeTreeの通常共有カレンダーからの自動取得は、このスターターには実装されていません。
取得方法を確定してから、別途安全に接続する必要があります。
